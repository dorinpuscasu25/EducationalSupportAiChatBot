# Asistent Academie — agent notes

Support chatbot for an academy's students. Students register, an admin approves
them, then they ask questions answered from the academy's own materials (RAG).

- `apps/api` — Go (gin + GORM). Auth/JWT, approval, chat (SSE), admin, and the
  knowledge base in `internal/knowledge` (extract → chunk → embed → hybrid search).
- `apps/web` — React 19 + Vite + TanStack Router/Query/Form + Tailwind v4.
  Layering: `api/` clients → `apiQuery/` hooks → `routes/` (thin) → `pages/`
  containers → `components/page/*` presentational pages. `routeTree.gen.ts` is
  generated by the router plugin; never edit it by hand.
- `documents/` — the source of truth for the knowledge base (not in git).
- Search runs entirely in PostgreSQL: pgvector + accent-insensitive Romanian
  full-text (`kb_unaccent`), merged with reciprocal rank fusion.
- Students only receive answer text; retrieved sources are stored with each
  answer and shown to administrators only.

Checks: `make check` (Go runs in Docker; Go is not required locally).
UI copy is Romanian; code comments and docs are English.
